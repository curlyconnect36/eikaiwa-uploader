このアプリについて

Eikaiwa Uploader は、運営者が自分で制作した英語学習動画（聞き流し英会話・リスニング・クイズなど）を、運営者自身の YouTube チャンネルにアップロードするための、個人用のツールです。運営者のパソコンの中だけで動き、一般の利用者向けには提供していません。

このツールが YouTube に対して行うことは、次のとおりです。

  • 運営者のチャンネルへの動画のアップロード（運営者が内容を確認した動画だけ。非公開または公開予約の状態でアップロード）
  • アップロードした動画の公開状態（非公開・公開予約・公開）の確認（運営者の制作管理表に反映するため）
  • アップロードした動画への字幕ファイル・サムネイル画像の設定、再生リストへの追加
  • 運営者のチャンネルの分析データ（再生回数・総再生時間など）の読み取り（制作の振り返りのため）

対象のチャンネル：

  • 毎日聞き流す社会人のリアル英会話
  • 毎日聞き流すビジネス英会話

About

Eikaiwa Uploader is a private, single-user tool. It runs only on the owner's own computer and is used by the owner to upload English-learning videos that the owner created to the owner's own YouTube channels. It is not offered to the public.

It uses the YouTube Data API and the YouTube Analytics API to upload videos that the owner has reviewed (as private or scheduled for publishing), set captions and thumbnails, add videos to playlists, check the publishing status of the owner's own videos, and read the owner's own channel statistics. See the Privacy Policy for how data is handled.
