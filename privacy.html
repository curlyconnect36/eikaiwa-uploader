Privacy Policy — Eikaiwa Uploader
ホーム / Home利用規約 / Terms of Service

1. 対象

このポリシーは、個人用ツール「Eikaiwa Uploader」（以下「本ツール」）が、YouTube API サービスを通じて扱う情報について説明します。本ツールは運営者本人だけが、運営者本人の Google アカウントと YouTube チャンネルに対して使います。

2. 利用する情報

本ツールは、運営者が Google のログイン画面で許可した範囲で、次の情報にアクセスします。

  • 運営者の YouTube チャンネルの基本情報（チャンネル名・チャンネルID）
  • 運営者のチャンネルの動画・字幕・サムネイル・再生リスト（アップロード・公開予約・設定のため）
  • 運営者がアップロードした動画の公開状態と公開日時（制作管理表に反映するため。読み取りのみ）
  • 運営者のチャンネルの分析データ（再生回数・総再生時間・登録者数など。読み取りのみ）

運営者以外の人の個人情報や、視聴者の個人情報は扱いません。

3. 利用の目的

  • 運営者が制作した動画を、運営者のチャンネルにアップロードし、字幕・サムネイルなどを設定するため
  • 運営者が自分のチャンネルの成果を振り返るため（運営者のパソコン上の管理表に表示）

4. 保存・共有・削除

  • ログイン情報（Google が発行するアクセス用の情報）と分析データは、運営者のパソコンの中にだけ保存します。外部のサーバーには送りません。
  • 取得した情報を、第三者に販売・提供・共有することはありません。広告にも使いません。
  • 本ツールのアクセスは、Google アカウントのサードパーティのアクセス設定からいつでも取り消せます。取り消すと、パソコンに保存したログイン情報は使えなくなり、運営者が該当ファイルを削除します。

5. YouTube・Google のポリシー

本ツールは YouTube API サービスを利用しています。YouTube の利用には YouTube 利用規約 が、Google による情報の取り扱いには Google プライバシーポリシー が適用されます。

本ツールによる Google API から取得した情報の利用と他のアプリへの転送は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

6. 変更・お問い合わせ

このポリシーを変更するときは、このページを更新します。
